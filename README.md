# Chapter10_BankingSystem

Simple C++ implementation of a banking system used for Chapter 10 exercises.

Languages
- C++ (primary)
- CMake (build)

Requirements
- C++17 compatible compiler (g++, clang++)
- CMake 3.10+

Build
1. Clone the repository:

   git clone https://github.com/liewvk/Chapter10_BankingSystem.git
   cd Chapter10_BankingSystem

2. Create a build directory and run CMake:

   mkdir build
   cd build
   cmake ..
   cmake --build .

Run
- After building, run the produced executable from the build directory. The executable name depends on the CMake configuration; look in the build directory for the binary (for example, `./BankingSystem`).
